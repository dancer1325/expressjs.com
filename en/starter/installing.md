# Installing

* install [Node.js](https://nodejs.org/)
  * | [Express 4.x](/{{ page.lang }}/4x/api.html), requires Node.js v0.10+
  * | [Express 5.x](/{{ page.lang }}/5x/api.html), requires Node.js 18+
* `npm install express` OR `npm install express --no-save`
  * `--no-save`
    * == install Express TEMPORARILY
